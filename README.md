# D&D Assistant (Frontend)

Веб-приложение для управления кампаниями, персонажами и мирами в Dungeons & Dragons. Клиентская часть проекта (Frontend).

## Краткое описание
Проект представляет собой интерактивный SPA (Single Page Application) D&D-помощник. В приложении реализованы интерфейсы для справочников правил, конструктора персонажей с отслеживанием характеристик и инвентаря, а также система создания авторских миров (World-building) с картами, локациями и NPC. 

## Стек технологий
* **Ядро:** React 19, TypeScript
* **Сборщик:** Vite 8
* **UI-библиотека:** Mantine (v8) для компонентов, форм, дат и уведомлений
* **Маршрутизация:** React Router v7
* **Сетевые запросы:** Axios
* **Тестирование и код-стайл:** Vitest, Storybook, ESLint, Stylelint, Prettier

## Структура проекта
Основные директории внутри `src/`:
* `api/` — конфигурация Axios и модули для взаимодействия с backend API.
* `components/` — переиспользуемые UI-компоненты (включая защиту маршрутов `AdminGuard`, редакторы статей `ArticleEditor` и модули миров).
* `pages/` — компоненты страниц, соответствующие маршрутам (CharacterSheet, Worlds, Rules, Editor и др.).
* `store/` — управление состоянием приложения (авторизация).
* `Router.tsx` — конфигурация всех маршрутов приложения.

## Как запустить
Проект использует менеджер пакетов Yarn (v4.13.0).

1. Установите зависимости:
   ```bash
   yarn install
   ```
2. Запустите сервер для разработки:
   ```bash
   yarn dev
   ```
3. Для сборки проекта (production):
   ```bash
   yarn build
   ```

## Переменные окружения
Для настройки подключения к серверу (Backend API) используется базовый URL в конфигурации Axios.
Рекомендуется использовать переменные окружения (например, в файле `.env` задать `VITE_API_BASE_URL`), чтобы легко переключаться между локальным сервером (по умолчанию `https://localhost:7178/api`) и production-окружением. Токены аутентификации сохраняются в localStorage на стороне клиента.

## Основные реализованные функции (UI)
* **Аутентификация и авторизация:** Клиентская маршрутизация с ограничением доступа (AdminGuard).
* **Справочник системы:** Интерфейсы для просмотра правил, заклинаний, предметов, классов и рас.
* **Управление персонажами:**
  * Интерактивный лист персонажа: отслеживание HP, спасбросков, характеристик, подготовленных заклинаний.
  * Управление инвентарем и экипировкой.
* **World-building (Миры и Кампании):**
  * Интерфейс создания миров, загрузки карт, добавления локаций и NPC.
  * Страницы кампаний с системой присоединения по инвайт-кодам.

## Интеграция с API
Все сетевые запросы инкапсулированы в `src/api/api.ts`. Настроены интерцепторы Axios для:
* Автоматического добавления JWT-токенов в заголовки (`Authorization: Bearer <token>`).
* Глобальной обработки ошибок (вывод уведомлений через `@mantine/notifications` при статусе `403 Forbidden`).
